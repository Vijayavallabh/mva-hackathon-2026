# Reuse the offline teaching kit

V39 changes the scientific framing and recording materials. The tested 18-case
teaching demo, decision contract and small ZIP remain the frozen v37 artifacts.
Open [the demo](track2-demo-v37.html) and follow [the kit guide](track2-community-kit-v37.md).
Run `uv run --offline --no-project python scripts/track2_demo_v37.py`.
The 17 synthetic examples and actual unmeasured HOLD case illustrate implementation,
not biological validation. There is no new kit, external user study or clinical result.
The [v39 proposal](track2-reviewer-brief-v39.md) starts with endogenous functional
qualification; the unchanged safety and missing-evidence rules still apply.
