# Reuse the offline teaching kit, version 42

The tested 18-case teaching demo, decision contract and small ZIP remain the frozen
v37 artifacts. This v42 guide only updates the current proposal links; it does not
claim a new kit or community adoption.
Open [the demo](https://github.com/Vijayavallabh/mva-hackathon-2026/blob/main/notes/track2-demo-v37.html) and follow [the kit guide](https://github.com/Vijayavallabh/mva-hackathon-2026/blob/main/notes/track2-community-kit-v37.md).
Run `uv run --offline --no-project python scripts/track2_demo_v37.py`.
The 17 synthetic examples and actual unmeasured HOLD case illustrate implementation,
not biological validation. There is no new kit, external user study or clinical result.
The current [proposal](https://github.com/Vijayavallabh/mva-hackathon-2026/blob/main/notes/track2-reviewer-brief-v42.md) starts with endogenous functional
qualification. The [v41 literature addendum](https://github.com/Vijayavallabh/mva-hackathon-2026/blob/main/notes/track2-literature-v41.md) adds checkpoint,
mitochondrial and proteostasis readouts without changing a drug decision. The
[v42 official refresh](https://github.com/Vijayavallabh/mva-hackathon-2026/blob/main/notes/track2-requirements-review-v42.md) documents delivery-context
clarifications. The unchanged safety and missing-evidence rules still apply.
