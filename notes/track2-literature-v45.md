# Track 2 public literature addendum, version 45

20 October 2026. This is a targeted falsification review of 2025-2026 checkpoint,
corona and computational drug-discovery literature. It is not a systematic review.
No protected subject data was accessed. It does **not** change any drug disposition:
everolimus remains a mechanistic probe on HOLD; HCQ remains reserve; no
NAD/SIRT2 intervention is promoted; no rescue priority, clinical exposure margin,
phase result or wet-lab validation is established.

## Newly selected records

1. **Norlichexanthone / griseofulvin / TPR / Mad1-BubR1** — Pham et al., [Bioorganic
   Chemistry 2026](https://doi.org/10.1016/j.bioorg.2026.110130), PMID 42330849.
   PubMed abstract says griseofulvin binds directly to Mad1 and BubR1, interrupts
   the Mad1-Mad2 interaction and induces mitotic death through multipolar spindles;
   norlichexanthone has higher cytotoxicity, disrupts SAC assembly and nuclear
   transport by binding TPR. The article is closed access. We read the PubMed
   abstract, PubMed summary, Crossref, Europe PMC and Unpaywall records; not the
   full text. This is **tumour-cell killing**, not deficient-normal rescue. It
   strengthens the reason to keep tumour killing and useful non-cancer function
   separate. It does not promote griseofulvin or norlichexanthone for MVA.

2. **TPX2/BUB1B computational inhibitors** — Kim et al., [Computational Biology and
   Chemistry 2026](https://doi.org/10.1016/j.compbiolchem.2026.109012), PMID 41895167.
   The abstract reports TPX2/BUB1B upregulation in breast cancer, virtual screening,
   docking and ADMET triage; vorinostat scored most strongly. We read the PubMed
   abstract/summary only, not the full text. This is cancer-cell antimitotic
   discovery. It does not show BUBR1 restoration or useful function in a
   deficient-normal model. It does not reopen vorinostat, which remains
   deprioritized in the v21 ledger.

3. **Aurora-B/BubR1 K250 acetylation axis** — [NAR 2026](https://doi.org/10.1093/nar/gkaf1517), PMID 41533580. The abstract reports S16/S39 phosphorylation, K250
   acetylation, fibrous-corona maintenance and MCC stability. This is already
   integrated in v41/v43 as a mechanistic readout. It is not evidence for a
   NAD/SIRT2 drug.

4. **BUB1/BUBR1 corona scaffolds** — [Science Advances 2025](https://doi.org/10.1126/sciadv.ady6890), PMID 40938979. The abstract reports two nonredundant BUB1/BUBR1 corona
   branches and a BUB1-ROD route. This strengthens corona architecture as a
   mechanistic endpoint, not a drug claim.

## Consequence for the proposal

1. Add griseofulvin and norlichexanthone to the explicit **tumour-killing/
   harmful-normal context** evidence map. They are contrary examples, not rescue
   candidates. If a future experiment uses them, it must be in cancer-cell context
   with non-cancer injury controls; do not transfer them to MVA.
2. Keep vorinostat and BUB1B antimitotic inhibitors in the tumour-only branch.
   Computational docking to BUB1B is not useful function and cannot rescue a
   deficient-normal cell.
3. Reinforce the current readout hierarchy:
   - direct mTORC1 engagement;
   - BUBR1/MAD2/ZW10 corona;
   - MCC/APC/C;
   - lagging DNA/anaphase bridges;
   - all-enrolled daughter fate, useful output and recovery;
   - mitochondrial/proteostasis injury.
4. No additional GPU campaign is justified by these abstracts. Docking and
   transcriptomic-pipeline claims in cancer models do not answer the decisive
   non-cancer functional question.

## Falsification/stop rule

| Claim to test | Support needed | Falsifier / stopping condition | Next discriminating action |
|---|---|---|---|
| Antimitotic BUB1B/TPR inhibitors help constitutional MVA | Useful non-cancer function improves without injury in a qualified BUB1B-deficient model | Tumour-cell death or corona disruption without useful deficient-normal output | Do not promote; keep tumour-only |
| Computational BUB1B docking identifies a rescue route | Endogenous deficit, target engagement and useful output in a qualified non-cancer model | Docking score or cancer-marker performance only | Stop before biological promotion |
